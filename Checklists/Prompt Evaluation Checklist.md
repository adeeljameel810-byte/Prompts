# Prompt Evaluation Checklist

Use this checklist to review a prompt before sharing or relying on it.

- [ ] The task has one clear primary objective.
- [ ] The role and audience are appropriate.
- [ ] Necessary context and source material are included.
- [ ] Constraints are specific and testable.
- [ ] The requested output format is unambiguous.
- [ ] Important assumptions are stated.
- [ ] The prompt avoids contradictory instructions.
- [ ] Sensitive information is excluded or handled safely.
- [ ] The result can be checked against explicit quality criteria.
- [ ] The prompt has been tested with at least one realistic example.

## Evaluation notes

Record the test input, expected behavior, observed result, and the next improvement. Comparing revisions makes prompt development more systematic and repeatable.
