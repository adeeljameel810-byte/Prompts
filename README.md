# Prompt Engineering Collection

A curated collection of reusable prompts for learning, research, writing, creativity, travel, advertising, technology, and cybersecurity.

## What is included

- **Creative thinking:** prompts for breakthrough ideas and innovative products.
- **Communication:** English improvement, translation, and clear rewriting.
- **Research and culture:** travel planning and global wisdom exploration.
- **Technology:** cybersecurity guidance and responsible technical analysis.
- **Marketing:** advertising concepts, positioning, and campaign ideas.

## How to use these prompts

1. Open the prompt that matches your task.
2. Replace bracketed placeholders with your own context.
3. Add constraints such as audience, tone, format, deadline, or budget.
4. Ask the model to state assumptions and identify uncertainty.
5. Review the response and iterate with specific feedback.

## Prompt quality checklist

Before using a prompt, confirm that it has a clear role, objective, context, constraints, and expected output format. The companion files in this repository provide templates, evaluation guidance, and contribution practices.

## Repository structure

- `Prompts/` — reusable prompt examples.
- `Templates/` — prompt-building templates for new use cases.
- `Guides/` — practical guidance for writing and improving prompts.
- `Checklists/` — safety and quality checks.
