# Contributing

Thank you for helping improve this prompt collection.

## Adding a prompt

1. Choose a descriptive filename that reflects the prompt's purpose.
2. Place the file in `Prompts/` unless it is a template, guide, or checklist.
3. Include a clear objective, useful context, constraints, and expected output format.
4. Use placeholders such as `[audience]` for details that users should customize.
5. Remove private data, credentials, and unverifiable claims.
6. Test the prompt with at least one realistic input before submitting it.

## Improving an existing file

Keep changes focused and explain what problem the revision solves. Preserve useful examples while correcting ambiguity, unsafe instructions, or outdated assumptions.

## Commit messages

Use a short, descriptive prefix such as `docs:`, `feat:`, `fix:`, or `chore:` followed by the change in the imperative mood.

## Review checklist

Before opening a pull request, confirm that the prompt is clear, safe, reusable, and consistent with the repository structure. Update the README when a new category or workflow is introduced.
