# Prompt Examples by Category

These examples demonstrate how to turn a broad request into a focused, reusable prompt.

## Learning

> Act as a patient tutor. Explain **[topic]** to **[audience level]** using a simple analogy, three key ideas, one worked example, and five review questions. Define unfamiliar terms and identify common misconceptions.

## Writing and editing

> Act as a precise editor. Improve the following **[text type]** for **[audience]** while preserving the original meaning. Return the revised version first, followed by a short table listing substantial changes and their reasons: **[text]**.

## Research

> Act as a research assistant. Analyze **[question]** using the supplied material. Separate established facts, reasonable inferences, and unanswered questions. Cite the relevant source for each important claim and avoid inventing references.

## Product ideation

> Act as a product strategist. Generate **[number]** ideas for **[audience]** who struggle with **[problem]**. For each idea, provide the value proposition, key feature, likely risk, and a low-cost experiment to test demand.

## Travel planning

> Act as a practical travel planner. Create a **[duration]** itinerary for **[destination]** with a **[budget]** budget and **[interests]** priorities. Include travel time between activities, accessibility considerations, alternatives for bad weather, and assumptions that need confirmation.

## Coding support

> Act as a senior developer. Review the following **[language/framework]** code for correctness, maintainability, security, and performance. Explain the highest-impact issues, propose a minimal fix, and include tests for the changed behavior: **[code]**.
