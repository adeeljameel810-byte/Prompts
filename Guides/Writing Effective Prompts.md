# Writing Effective Prompts

Good prompts make the desired task, context, and output explicit. Use this workflow when creating or improving a prompt.

## 1. Define the outcome
Describe what a successful answer should help you accomplish. Prefer a concrete deliverable over a broad request.

## 2. Add useful context
Include the audience, domain, source material, constraints, and any assumptions the model should know.

## 3. Set boundaries
Specify length, tone, format, exclusions, deadline, budget, or technical limitations when they matter.

## 4. Request a structured result
Name the sections, fields, table columns, or steps you expect. This makes responses easier to review and reuse.

## 5. Include an example when helpful
A small input/output example can clarify style and edge cases better than additional instructions.

## 6. Iterate deliberately
Test the prompt with representative inputs, note what was missing, and change one part at a time.

### A compact formula

**Role + task + context + constraints + output format + quality criteria**

Avoid asking for hidden reasoning. Instead, request a concise explanation, assumptions, checks, or evidence that can be reviewed.
